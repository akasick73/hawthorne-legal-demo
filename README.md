# Hawthorne Legal — Portfolio Concept

Fictional Fort Collins boutique law-firm website built as a portfolio demonstration of strategy, positioning, copywriting, design, development, SEO/AEO structure and conversion planning.

## Cloudflare Pages / GitHub auto-deploy
This project is intentionally static and needs no framework or build step.

1. Create a GitHub repository (recommended: `hawthorne-legal-demo`) and upload every file in this folder to the repository root.
2. In Cloudflare: Workers & Pages → Create → **Continue to Pages** → Import an existing Git repository.
3. Select the GitHub repository.
4. Production branch: `main`.
5. Framework preset: `None`.
6. Build command: leave blank.
7. Build output directory: `.`
8. Save and Deploy.

Once that GitHub repository is connected, Cloudflare Pages will automatically redeploy whenever changes are committed to `main`. No repeated manual Cloudflare upload is needed.

## Important
Hawthorne Legal and Elizabeth Hawthorne are fictional. Keep the visible Portfolio Concept disclosure when using this as a public portfolio example.
